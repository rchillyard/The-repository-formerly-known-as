has mean(iterations 1–5) ÷ mean(iterations 6–10) > 1.10, so the row was still speeding up inside its measurement window
and its score is above steady state (main document, Marks). § after a cell = every one of the row's five forks has t <

below). "—" = the (method, params) row is absent because the benchmark throws for that parameter (24 rows, listed in the
main document's disclosure d). The english and chinese rows of the two string classes and every `sharedPrefix*` row sort
the `9bb0385` corpora and are not comparable with request 11 (`corpus changed (9bb0385)`). Methods are columns; the main
